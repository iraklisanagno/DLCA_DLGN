Differentiable logic gate networks learn Boolean functions on a fixed predecessor graph, making connectivity a constraint on accuracy at a given gate budget. Learned routing relaxes this constraint but increases training memory. We present LogicConnect, a method that designs structured connectivity before gate-function training. Semantic input pairing preserves image-source relationships, while regular multiscale matchings organize deeper connections under a degree-first selection rule. The construction supports dense and convolutional networks without trainable routing parameters or additional inference operators. Across MNIST, Fashion-MNIST, and CIFAR-10, we evaluate hardened accuracy, training resources, and structural ablations. LogicConnect improves dense CIFAR-10 test accuracy by 3.18–4.59 percentage points across three sizes and three paired seeds. Convolutional S/M models gain 3.26/2.08 points in single-seed tests, although replicated S validation remains inconclusive. Compared with learned Top-32 routing, LogicConnect uses 93.7–94.2\% less peak GPU memory and 80\% fewer trainable parameters, at an accuracy cost of 1.84–5.30 points. Degree-preserving ablations identify first-layer structure as the strongest measured dense contributor. These results establish offline connectivity design as a useful accuracy/resource operating point for logic gate networks.
