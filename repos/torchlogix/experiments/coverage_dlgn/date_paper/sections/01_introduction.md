# Introduction

Differentiable logic gate networks (DLGNs) represent learned feature transformations with Boolean gates, connecting neural network training to circuit design [@petersen2022]. Continuous relaxations enable gradient-based training, after which each gate is assigned a discrete Boolean function. The resulting classifier is therefore defined by its gate functions and the connections between them.

Connectivity is particularly restrictive in networks composed of two-input gates. Each gate combines only its assigned signals, and subsequent layers inherit the combinations available from preceding layers. Gate-function optimization changes how these signals interact, but cannot introduce an absent connection. Consequently, accuracy at a fixed depth and gate count depends partly on which signals are brought together throughout the network.

Existing approaches use fixed random graphs to avoid trainable connection parameters [@petersen2022; petersen2024], or optimize gate functions and predecessor selection jointly through learned routing [@mommen2025; fojcik2026]. Learned routing explores alternative input assignments, but processing candidate inputs increases training requirements even when the final network retains two connections per gate. This trade-off motivates designing structured connections before training to improve accuracy without adding trainable routing parameters.

Uniform predecessor use does not determine which features a gate can combine: two graphs may use every input equally often while forming different pairs. In a dense CIFAR-10 ablation, randomizing first-layer pairs without changing predecessor degrees reduces validation accuracy by 4.49 percentage points when deeper layers remain structured. Since the native dense random baseline already balances fan-out, balance alone cannot explain the benefit of structured connections. This observation motivates a design that considers signal identities alongside their frequency of use. For image inputs, those identities provide channel, spatial, and encoding information that an index-only assignment does not explicitly preserve.

In this work, we propose LogicConnect, a structured connectivity method that forms input pairs using image-source relationships and organizes deeper connections through regular multiscale matchings. Matching selection prioritizes balanced predecessor use and employs structural ancestry to distinguish equally balanced alternatives. The convolutional construction assigns channel pairs while preserving spatial sampling and shared logic trees. The same principles therefore apply across dense and convolutional DLGNs without additional inference operators.

Our main contributions are as follows:

- We introduce a connectivity construction that combines semantic input pairing with multiscale matching for dense layers, convolutional channel groups, and convolutional classifiers.
- We evaluate the accuracy and training-resource trade-off across MNIST, Fashion-MNIST, and CIFAR-10. LogicConnect improves dense CIFAR-10 test accuracy by 3.18–4.59 percentage points across three sizes and three paired seeds. Compared with learned Top-32 routing, it uses 93.7–94.2% less peak GPU memory at an accuracy cost of 1.84–5.30 points.
- We isolate the effects of first-layer and deeper-layer connectivity using degree-preserving ablations, and examine simpler construction rules, alternative gate training, and distribution shift to characterize when the design is effective.
